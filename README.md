# 🧢 PM試験クエスト

IPA「プロジェクトマネージャ試験」の午前Ⅱ・午後Ⅰ・午後Ⅱを、ゲーム感覚で続けられる学習Webアプリです。
登録不要・無料。記録はブラウザ（localStorage）に保存されます。

## できること

- **午前Ⅱ**：135問（IPA過去問79問＋頻出論点のオリジナル56問）。まだ解いていない問題・しばらく解いていない問題から優先して出題
  - 分野別のステージ、今日の5問、苦手復習（間隔反復）、本番模試（25問・40分）、年度別
  - 過去問の正解は IPA 公表の解答例と照合済み
- **午後Ⅰ**：過去10年30問の出題テーマ一覧、解答の型ドリル、オリジナル事例8題の記述トレーニング（字数カウンタ・キーワード判定・自己採点）
- **午後Ⅱ**：過去10年20テーマの論文トレーナー（2時間タイマー、設問ア〜ウの字数ゲージ、骨子メモ、自動保存、セルフチェック）
- **続けたくなる仕組み**：XP・レベル・称号、連続日数とシールド、コンボ、デイリークエスト、宝箱（ランダム報酬）、バッジ20種
- **手応えの演出**：ヒットストップ、ヒットマーク、画面振動、フラッシュ、合成効果音、疑似ハプティクス（Android：Vibration API／iOS 18以降のSafari：スイッチ型チェックボックス）
- マスコット：現場監督の「ポコ」（オリジナル・紫の体＋黄色いヘルメット）
- フォント：LINE Seed JP（Google Fonts）
- アイコン：Material Symbols Rounded（必要なアイコンだけを抜き出して index.html に埋め込み。全OSで同じ見た目）

## ファイル構成

```
index.html          ← 公開用（ビルド済み）
favicon.ico ほか    ← favicon（16/32/48）、apple-touch-icon、PWAアイコン、manifest.webmanifest
ogp.jpg             ← OGP画像（1200×630）
src/app.html        ← アプリ本体（UI・ロジック）
src/data_am2.js     ← 午前Ⅱの問題データ
src/data_pm.js      ← 午後Ⅰ・午後Ⅱのデータ
tools/build.py      ← src から index.html を生成
```

`src/` を編集したら、`python3 tools/build.py` で `index.html` を作り直してください。

## 公開（GitHub Pages）

リポジトリの Settings → Pages → Build and deployment で
「Deploy from a branch」「main」「/ (root)」を選んで保存すると、`index.html` がそのまま公開されます。

## マスコット「ポコ」

紫の体に黄色いヘルメットをかぶった現場監督の「ポコ」（オリジナル）。SVGでアプリ内に描画しているので画像ファイルは不要です。
表情は happy（いつも）／wow（正解・クリア）／sad（不正解）の3種類。色は `src/app.html` の `POCO` で変更できます。

## 問題データの差し替え

`src/data_am2.js` の配列 `window.AM2` に1問1オブジェクトで入っています。

```js
{id:"r6-1", src:"R6秋 問1", cat:"int", q:"問題文", ch:["ア","イ","ウ","エ"], a:1, ex:"解説"}
```

- `a` は正解の添字（0=ア 1=イ 2=ウ 3=エ）
- `cat` は分野（int / scope / sched / cost / qual / team / stake / risk / dev / svc / law / sec）
- `orig:1` を付けるとオリジナル問題として表示
- 表は `tbl:[["見出し",...],["値",...]]` で描画

平成30年度〜令和7年度の午前Ⅱは本文が未収録です（オリジナル問題で補っています）。
